# Smol Iso World

Tiny living pixel-art worlds.

Live at **https://smol-iso-world.vercel.app**

Every scene is an animated isometric pixel-art diorama drawn entirely in code: no images,
sprite sheets or libraries. Each one is a single HTML file that runs at 60 fps, loops
seamlessly, and plays the same way for a given seed.

## Scenes

| Scene | Path | What happens |
| --- | --- | --- |
| Rainy Night Dollhouse | [`/dollhouse/`](https://smol-iso-world.vercel.app/dollhouse/) | A girl reads by the fire on a stormy night while her dachshund and cat doze, wander and snuggle. Loops every 120 seconds. |
| Sky Island | [`/sky-island/`](https://smol-iso-world.vercel.app/sky-island/) | An autumn island above the clouds, from dusk through the night to dawn. A girl reads on the porch, a boy fishes off the edge and a cat hunts the pond. Loops every 300 seconds. |
| Winter Wonderland | [`/winter-wonderland/`](https://smol-iso-world.vercel.app/winter-wonderland/) | A snowy valley below the mountains, from golden hour to the blue hour and back. Kids sled and build a snowman, a big dog knocks it down, and the Sky Island couple rock on the cabin porch with cocoa while their cat comes out through the cat flap to snuggle, and a yeti wanders through the forest. Loops every 240 seconds. |

## Repository layout

```
public/              what Vercel serves
  index.html         the home page: pick a world and it plays live, full window
  posters/           one still per world, captured by tools/posters.js
  dollhouse/         built scenes (generated by tools/build.sh)
  sky-island/
  winter-wonderland/
scenes/
  dollhouse/         scene source: 00_head.html, NN_*.js, 99_tail.html
  sky-island/
  winter-wonderland/
tools/
  build.sh           builds scenes into public/<scene>/index.html
  posters.js         captures each world's poster from the scene itself
  check/             screenshot, zoom, performance, loop-seam and timeline checks
skills/iso-pixel/    the Claude skill describing how these scenes are made
vercel.json          serves public/, adds trailing slashes
.github/workflows/   CI checks on every push and pull request
```

## Working on a scene

Build after editing a scene's source:

```bash
tools/build.sh dollhouse
```

Open `public/dollhouse/index.html` in a browser to view it. Useful URL options:

- `?debug=1` opens the controls panel (speed, time scrub, seed, a toggle per effect)
- `?seed=2` picks a different story in the dollhouse (seeds where `seed % 3 == 2` play the "upstairs" story)
- `?loop=0` turns the loop off (the dollhouse plays endless varied episodes; Sky Island and Winter Wonderland have one story)
- `?fixed=1` steps exactly 1/60 s per frame, for recording
- `?embed=1` shows the bare scene with no controls, which is how the home page plays it

Keyboard: `D` controls, `L` loop on/off, `Space` pause, arrows scrub, `[` `]` speed.

The checks need Node and Playwright with Chromium:

```bash
node tools/check/perf.js     "$PWD/public/dollhouse/index.html"
node tools/check/seam.js     "$PWD/public/dollhouse/index.html" "seed=7" "seed=2"
node tools/check/validate.js "$PWD/public/dollhouse/index.html"
```

## Adding a new scene

1. Create `scenes/<name>/` with its source and run `tools/build.sh <name>`. Start from an existing
   scene's `00_head.html` and `20_main.js` so it keeps embed mode and the link back to the home page.
2. In `public/index.html`, copy one world's `<li>` and fill it in: `data-world`, its text, the two
   world colours, and `data-t`, the moment used for the poster and where live play starts.
3. Run `node tools/posters.js <name>`, then set `--cx` and `--cy` to the top-left of a small crop of
   the poster (native pixels) for its thumbnail.
4. Commit and push (see below).

## Deploys and checks

- **Vercel** deploys every push to `main` to https://smol-iso-world.vercel.app and gives each
  pull request its own preview URL. It serves `public/` as-is; there is no build step on Vercel.
- **GitHub Actions** (`.github/workflows/ci.yml`) runs on every push and pull request. It rebuilds
  the scenes and fails if `public/` doesn't match the source (run `tools/build.sh` before
  committing), then checks that each scene loops seamlessly and that its story timelines have no
  gaps. Frame times are reported but don't fail the run.

## Recording a long video

Open the scene with `?fixed=1`, record one loop, and repeat it. Every animated system has a
period that divides the scene's loop length, so the end joins the start without a seam.
